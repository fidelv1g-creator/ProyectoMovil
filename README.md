# Home Control

Aplicación Android nativa con interfaz oscura y compacta.

## Primera versión
- Sección SALÓN.
- Botones ENCENDER TELE y APAGAR TELE.
- La conexión con Google Home todavía está pendiente: los botones muestran un aviso y no envían comandos todavía.

## Compilación
GitHub Actions compila un APK de depuración en cada push a `main` y permite lanzarlo manualmente desde la pestaña Actions.
